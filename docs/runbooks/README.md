# Runbooks

This repository has no daemon, service, or deployed runtime to start, stop, or restart. The
operator-facing cache and release commands live in the root [README](../../README.md) and the
maintainer validation requirements live in [CONTRIBUTING.md](../../CONTRIBUTING.md).

Add a dated runbook here only for a real operational procedure with preconditions, safe execution,
recovery steps, and its applicable release or platform boundary.
